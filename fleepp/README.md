# 📱 FLEEPP — Education Management App

Барномаи мобилии идоракунии маркази таълимӣ (React Native + Expo Router).
Ин версия **прототипи корӣ** аст: тамоми маълумот (довталабон, муаллимон,
волидайн, натиҷаҳо, SMS) сохта (mock) шудааст ва дар хотираи дастгоҳ
(AsyncStorage) нигоҳ дошта мешавад — бидуни backend ё сервери воқеӣ.

## Сохтор

| Бахш | Мазмун |
|---|---|
| 🔐 Воридшавӣ | 4 нақш: Admin, Teacher, Student, Parent — ҳар кадом бо ҳисоби намунавӣ |
| 📊 Асосӣ (Dashboard) | Шумораи довталабон/гурӯҳ/муаллим, статистика, рейтинги беҳтарин |
| 👨‍🎓 Довталабон | Профили пурра: баллҳо, гурӯҳ, муаллим, натиҷаи ҳамаи санҷишҳо, графики пешрафт |
| 👨‍🏫 Муаллимон | Профил, фан, гурӯҳҳо, донишҷӯён, миёнаи натиҷа |
| 👨‍👩‍👦 Волидайн | Рақами тасдиқшуда, иҷозати алоқа, пайванд ба таърихи SMS |
| 📨 SMS | Admin → интихоби довталаб → навиштан ва фиристодани SMS → таърих ва статус |
| 📈 Статистика | Натиҷаи умумӣ, рейтинг, натиҷаи гурӯҳҳо, пешрафт, натиҷаи муаллимон |
| 🏫 Дар бораи FLEEPP | Таърих, мақсад, муаллимон, дастовардҳо, галерея, тамос |

## Технология

- **Expo SDK 57** + **React Native 0.86** + **TypeScript**
- **expo-router** — файл-асосии навигатсия (Stack + Tabs, роҳҳо бо нақш маҳдуд шудаанд)
- **@react-native-async-storage/async-storage** — нигоҳдории сессия ва таърихи SMS
- **react-native-chart-kit** + **react-native-svg** — графики пешрафт
- Маълумот: `src/data/*` (сохта, вале воқеӣ ба назар мерасад)

## Роҳандозӣ

```bash
cd fleepp
npm install
npx expo start          # барои Android/iOS/Expo Go
npx expo start --web    # пешнамоиш дар браузер
```

## Маҳдудиятҳои прототип

- Backend ва базаи маълумоти воқеӣ нест — ҳама маълумот дар `src/data/*` сохта шудааст.
- Фиристодани SMS **тақлид** (simulate) карда мешавад: пас аз 1.8 сония статус
  худкор ба «дастрас шуд» иваз мешавад. Барои пайвастшавӣ ба провайдери воқеии
  SMS (масалан Eskiz, Twilio) бахши `src/context/SmsContext.tsx`-ро иваз кунед.
- Аутентификатсия сода аст (муқоисаи бевосита бо рӯйхати `src/data/users.ts`),
  бе ҳашкунии рамз — барои production бояд бо backend ва JWT/OAuth иваз шавад.
