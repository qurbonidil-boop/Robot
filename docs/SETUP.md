# Насб ва кор кардани систем — қадам ба қадам

Ин ҳуҷҷат ба саволҳои "код чи тавр ба робот медарояд" ва "чи тавр кор мекунад"
ҷавоб медиҳад.

## Тасвири умумии кор

Ду компютери **ҷудогона** дар дохили як робот ҳастанд, ҳар кадом коди худро дорад:

| Компютер | Забон | Коди он дар куҷо | Чи тавр бор мешавад |
|---|---|---|---|
| **Arduino** | C++ (`.ino`) | `firmware/arduino/robot_motion/` | Як бор, тавассути **Arduino IDE** аз ноутбук/компютери шумо, бо кабели USB |
| **Raspberry Pi** | Python | `raspberry_pi/` | Файлҳо ба SD-корти Raspberry Pi нусхабардорӣ мешаванд ва бо `python3 main.py` иҷро мешаванд |

Ин ду компютер баъдан бо ҳам тавассути **як кабели дигари USB** (RPi ↔ Arduino)
пайваст мешаванд ва бо ҳам "гап мезананд" (протоколи Serial, дар README тасвир шудааст).

---

## Қадами 1 — Бор кардани коди Arduino (firmware)

Ин корро **як бор** мекунед, пеш аз он ки Arduino дар дохили корпуси робот
насб шавад.

1. Дар компютери худ **Arduino IDE**-ро насб кунед (arduino.cc/en/software).
2. Arduino Uno/Nano-ро бо кабели USB ба компютер васл кунед.
3. Дар Arduino IDE: **Tools → Board** → "Arduino Uno" (ё Nano)-ро интихоб кунед.
4. **Tools → Port** → портеро, ки Arduino нишон медиҳад, интихоб кунед.
5. **Tools → Manage Libraries** → `Adafruit NeoPixel`-ро ҷустуҷӯ карда насб кунед.
6. Файли `firmware/arduino/robot_motion/robot_motion.ino`-ро кушоед.
7. Тугмаи **Upload** (стрелкаи →)-ро пахш кунед.
8. Агар хато набошад — коди Arduino акнун **дар дохили худи чипи Arduino нигоҳ
   дошта мешавад** (мисли хотираи доимӣ). Кабели USB-ро канда метавонед, коди
   он намеравад — ҳар бор, ки барқ медиҳед, ҳамон барнома кор мекунад.

**Санҷиш пеш аз давом додан:** дар Arduino IDE **Tools → Serial Monitor**-ро
кушоед (baud = 115200), нависед `PING` ва Enter занед — бояд `PONG` баргардад.
Сипас `MOVE:150,150` нависед — ҳарду мотор бояд кор кунанд.

## Қадами 2 — Гузоштани коди Python ба Raspberry Pi

Раванди коркарди коди Python дигар аст: он ба SD-корт нусхабардорӣ мешавад
ва **ҳар бор**, ки роботро фаъол мекунед, аз нав иҷро мешавад (на "бор карда
мешавад" мисли Arduino).

### 2.1. Тайёр кардани Raspberry Pi
1. Тавассути **Raspberry Pi Imager** системаи "Raspberry Pi OS (64-bit)"-ро ба
   SD-корт насб кунед. Ҳангоми насб, SSH-ро фаъол кунед ва Wi-Fi/парол таъин
   кунед (тугмаи ⚙️ дар Imager).
2. SD-кортро ба Raspberry Pi гузоред, барқ диҳед, тахминан 1 дақиқа интизор шавед.
3. Аз компютери худ пайваст шавед: `ssh pi@<IP-и-Raspberry-Pi>`

### 2.2. Гирифтани коди лоиҳа ба Raspberry Pi
Ду роҳ ҳаст:

**Роҳи A — тавассути git (тавсияшуда, агар репозиторий дар GitHub бошад):**
```bash
git clone https://github.com/qurbonidil-boop/Robot.git
cd Robot/raspberry_pi
```

**Роҳи B — тавассути scp аз компютери худ (агар git набошад):**
```bash
scp -r raspberry_pi pi@<IP-и-Raspberry-Pi>:~/Robot-raspberry_pi
```

### 2.3. Насби вобастагиҳо (dependencies)
```bash
cd ~/Robot/raspberry_pi   # ё роҳи дигаре, ки нусхабардорӣ кардед
sudo apt update
sudo apt install -y python3-venv python3-pip portaudio19-dev espeak-ng \
    libatlas-base-dev
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2.4. Танзими config.yaml
```bash
cp config.example.yaml config.yaml
nano config.yaml
```
Дар он ҷо пур кунед:
- `anthropic_api_key` — калиди API-и Claude (аз console.anthropic.com мегиред)
- `serial_port` — баъд аз пайваст кардани Arduino санҷед: `ls /dev/tty*`
  (одатан `/dev/ttyUSB0` ё `/dev/ttyACM0`)
- `camera_index` — одатан `0`

### 2.5. Иҷро кардани робот
```bash
python3 main.py
```
Агар ҳама дуруст бошад — дар терминал "Робот омода аст. Гап занед..." пайдо мешавад.

### 2.6. (Ихтиёрӣ) Худкор оғозшавӣ ҳангоми барқ додан
Барои он ки робот ҳар бор, ки барқ медиҳед, худкор кор кунад (бе ворид шудан
бо SSH), файли systemd созед:

```bash
sudo nano /etc/systemd/system/robot.service
```
Мазмуни файл:
```ini
[Unit]
Description=Роботи сӯҳбаткунанда
After=network.target

[Service]
ExecStart=/home/pi/Robot/raspberry_pi/venv/bin/python3 /home/pi/Robot/raspberry_pi/main.py
WorkingDirectory=/home/pi/Robot/raspberry_pi
User=pi
Restart=on-failure

[Install]
WantedBy=multi-user.target
```
Фаъол кардан:
```bash
sudo systemctl enable robot.service
sudo systemctl start robot.service
sudo journalctl -u robot.service -f   # барои дидани лог/хатоҳо
```

## Дастҳо (даст) — тарҳи оянда

Дар версияи 1 даст нест (шумо худатон гуфта будед "баъдтар илова мешавад").
Вақте омода шудед, тарҳи пешниҳодшуда чунин аст:

**Механикӣ:**
- Ҳар даст = 2–3 сервомотор (SG90 ё MG90S барои қувваи бештар): 1 барои China
  китф (елка — боло/поён), 1 барои оринҷ (арм — хам шудан), 1 (ихтиёрӣ) барои
  панҷа (кушодан/пӯшидан — grip).
- Дастҳо бо винт/брекети хурд ба паҳлӯҳои тан (қисми "Тан" дар меъморӣ) васл
  мешаванд, на ба поён (ки моторҳои ҳаракат доранд).

**Электроника:**
Arduino Uno танҳо ~6 pin PWM озод дорад — барои 2 даст (то 6 сервомотор) кофӣ
намерасад агар сар ҳам сервомотор дошта бошад. Бинобар ин лозим мешавад:
- Плитаи **PCA9685** (16-канали сервo-драйвер, тавассути I2C) илова кунед —
  арзиш ~$3–5. Ҳамаи сервомоторҳои даст+сар ба он васл мешаванд, PCA9685 худ
  ба Arduino (ё бевосита ба Raspberry Pi) тавассути 2 сим (SDA/SCL) пайваст мешавад.
- Протоколи Serial дар firmware бо фармони нав васеъ мешавад, масалан:
  `ARM:LEFT:SHOULDER:90` — ҳамон принсипи `HEAD:pan,tilt`, танҳо каналҳои
  бештар.

Ин тағирот ба лоиҳаи ҳозира зарар намерасонад — коди ҳозира тарҳрезӣ шудааст,
ки бидуни бозсозии калон васеъ шавад (фармонҳои Serial-и нав илова мекунед,
боқимонда ҳамон тавр мемонад).

## Пой (по) — чаро дар версияи 1 нест

Шумо худатон дар дархости аввал навишта будед: "ҳоло пойҳои дупоя намехоҳам".
Бинобар ин ҳаракати робот тавассути **чархҳо** аст, на пойҳо:
- 2 чархи мотордор (чап/рост) — самти ҳаракат ва гардишро таъин мекунанд
  (агар чархи чап тезтар аз рости гардад — робот ба рост мегардад, ва ҳ.к.)
- 1 чархи такягоҳ (caster wheel) — нуқтаи сеюми мувозинат, худ мотор надорад.

Агар дар оянда хостед робот бо пой (дупоя) ҳам равад — ин лоиҳаи комилан
алоҳида ва хеле мураккабтар аст (тавозун/баланс лозим мешавад, IMU-сенсор,
6+ сервомотор барои ҳар по). Тавсия: аввал версияи чархдорро пурра ба анҷом
расонед, сипас агар хоҳед, "версияи 2 — пой" -ро ҳамчун лоиҳаи алоҳида оғоз кунед.
