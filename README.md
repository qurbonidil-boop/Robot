# 🤖 Роботи Сӯҳбаткунанда — 50 см (Версия 1)

Лоиҳаи сохтани роботи хонагии 50 сантиметрӣ, ки метавонад бо одам бо овоз сӯҳбат кунад,
чеҳраи одамро бубинад, сарашро ҳаракат диҳад ва бо чашмони LED эҳсосот нишон диҳад.

Поёни робот мисли робот-чангкашак кор мекунад: ду чархи мотордор + сенсори масофасанҷ
барои пешгирӣ аз бархӯрд бо монеаҳо. Пойҳо (дупоя) дар версияи 1 нест.

---

## 0. Меъмории умумӣ

```
                ┌─────────────────────────┐
   САР          │  Камера, 2 сервомотор    │
   (Head)       │  (pan/tilt), LED чашм×2  │
                └───────────┬─────────────┘
                            │ USB / GPIO
                ┌───────────┴─────────────┐
   ТАН          │   Raspberry Pi 4        │  ← "МАҒЗ"
   (Body)       │   AI, STT, TTS, Camera, │
                │   Хотира (SQLite)       │
                └───────────┬─────────────┘
                            │ USB-Serial (UART)
                ┌───────────┴─────────────┐
   ПОЁН         │   Arduino Uno/Nano       │  ← "ХАРАКАТ"
   (Base)       │   Моторҳо, HC-SR04,     │
                │   сервои сар, LED       │
                └───────────┬─────────────┘
                            │
                  2 чархи мотордор + чархи такягоҳ
```

**Тақсимоти вазифаҳо:**
- **Raspberry Pi** — "мағзи" робот: гӯш кардан (STT), фикр кардан (AI), гап задан (TTS),
  дидан (камера + шинохти чеҳра), хотира. Ба Arduino фармонҳои содда мефиристад
  (масалан "ба пеш рав", "сарро ба чап гардон", "чашмҳоро сабз кун").
- **Arduino** — "рефлексҳо": идораи мустақими моторҳо, хондани сенсори масофа ва
  **истодани худкор пеш аз бархӯрд** (ҳатто агар Raspberry Pi фармони ҳаракат дода бошад),
  идораи сервомоторҳои сар ва LED-чашмҳо.

Ин ҷудокунӣ муҳим аст: агар барномаи AI дар Raspberry Pi "ях занад" ё сует кунад,
Arduino боз ҳам роботро аз афтодан/бархӯрдан нигоҳ медорад.

## 2. Нақшаи кор — ҳафта ба ҳафта

> Қоида: **ҳар қисмро алоҳида, дар рӯи миз, пеш аз васл кардан ба корпус санҷед.**
> Ҳеҷ гоҳ якбора ҳама чизро ҷамъ карда нахоҳед санҷид — хатогиро ёфтан душвор мешавад.

### Ҳафтаи 0 — Тайёрӣ
- Ҳамаи қисмҳоро фармоиш диҳед.
- Дар компютери худ Python 3.11+ ва Arduino IDE-ро насб кунед.
- Raspberry Pi OS-ро дар SD-корт насб кунед, SSH-ро фаъол кунед.
- **Санҷиш:** аз ноутбук ба Raspberry Pi тавассути SSH пайваст шавед.

### Ҳафтаи 1 — Асосҳои ҳаракат (Arduino)
- Arduino + драйвери мотор + 2 моторро дар рӯи миз васл кунед (бе корпус).
- Кодҳои `firmware/arduino/robot_motion` (дар ин репозиторий) насб кунед.
- **Санҷиш:** тавассути Serial Monitor фармон фиристед `MOVE:150,150` ва бинед, ки
  ҳарду мотор мечарханд; `STOP` — бояд бозистанд.

### Ҳафтаи 2 — Сенсори масофа (бехатарӣ)
- HC-SR04-ро пеши робот васл кунед.
- Кодро бо хониши масофа пурра кунед (аллакай дар firmware ҳаст).
- **Санҷиш:** дасти худро пеши сенсор гузоред — робот бояд ҳаракатро худкор бозистонад,
  ҳатто агар шумо фармони `MOVE` фиристода истода бошед.

### Ҳафтаи 3 — Корпус ва механика
- Шассиро (поёни даврашакл) созед: 2 мотор + чархи такягоҳ + ҷои батарея.
- Ҳамаро дар корпус ҷойгир кунед, вазни воқеиро санҷед.
- **Санҷиш:** робот бо вазни пурра рост ба пеш/ақиб/чап/рост ҳаракат карда тавонад.

### Ҳафтаи 4 — Пайвасти Raspberry Pi ↔ Arduino
- Raspberry Pi-ро тавассути кабели USB ба Arduino пайваст кунед.
- Скрипти `raspberry_pi/brain/motion_link.py`-ро санҷед — аз Python фармон фиристед.
- **Санҷиш:** аз Python `python3 -c "..."` фармони ҳаракат фиристед, робот ҳаракат кунад.

### Ҳафтаи 5 — Гӯш кардан (STT)
- Микрофонро ба Raspberry Pi васл кунед.
- `brain/speech_to_text.py`-ро санҷед.
- **Санҷиш:** гап занед, скрипт матни шуморо дар терминал чоп кунад.

### Ҳафтаи 6 — AI ва гуфтор (TTS)
- API key барои AI (масалан Claude API) созед, дар `config.yaml` гузоред.
- `brain/ai_chat.py`-ро санҷед — савол диҳед, ҷавоб гиред (матн).
- Баландгӯякро васл кунед, `brain/text_to_speech.py`-ро санҷед.
- **Санҷиш:** савол бо овоз диҳед → робот бо овоз ҷавоб диҳад.

### Ҳафтаи 7 — Камера ва шинохти чеҳра
- Камераро дар сар ҷойгир кунед.
- `brain/vision.py`-ро санҷед (шинохти чеҳраи оддӣ бо OpenCV).
- **Санҷиш:** пеши камера биистед — скрипт "чеҳра ёфт шуд" чоп кунад.

### Ҳафтаи 8 — Сар ва чашмҳо
- 2 сервомоторро барои pan/tilt ва LED-ҳалқаҳоро васл кунед.
- Рафтори "ба чашм нигоҳ кардан": вақте чеҳра ёфт мешавад, сар ба он тараф гардад.
- Рангҳои чашм: гӯш кардан = кабуд, фикр кардан = зард, гап задан = сабз.
- **Санҷиш:** ҳангоми сӯҳбат чашмҳо ва сар мутаносибан кор кунанд.

### Ҳафтаи 9 — Хотира
- SQLite-ро тавассути `brain/memory.py` васл кунед: номи корбар, таърихи сӯҳбат.
- **Санҷиш:** номи худро гӯед, роботро хомӯш карда аз нав кунед — бояд номи шуморо
  дар сӯҳбати нав ба ёд орад.

### Ҳафтаи 10 — Якҷоякунӣ ва санҷиши ниҳоӣ
- Ҳамаро тавассути `raspberry_pi/main.py` якҷоя кунед.
- Санҷиши бехатарӣ: робот дар ҳолати сӯҳбат агар ба монеа наздик шавад, бояд бозистад.
- Демо ба дӯстон/оила нишон диҳед 🎉

## 3. Барномасозӣ: забонҳо ва пайвасти системаҳо

**Забонҳое, ки бояд омӯзед (бо тартиб):**
1. **Python (асосӣ)** — асосҳо, сипас `threading`/`asyncio` (барои кор дар як вақт бо
   микрофон + камера + AI).
2. **`pyserial`** — барои гуфтугӯи Raspberry Pi бо Arduino тавассути USB.
3. **OpenCV (Python)** — асосҳои коркарди тасвир, шинохти чеҳра.
4. **Arduino C++** — оддӣ аст агар Python донед: `setup()`/`loop()`, PWM
   (`analogWrite`), китобхонаҳои `Servo` ва `Adafruit_NeoPixel`.

**Тарзи пайвасти системаҳо:**

```
Микрофон → SpeechRecognition/Vosk (STT) → матн
   матн → Anthropic API (Claude) → матни ҷавоб
   матни ҷавоб → pyttsx3/piper (TTS) → Баландгӯяк
   Камера → OpenCV (шинохти чеҳра) → координатаи чеҳра → фармони HEAD ба Arduino
   Raspberry Pi ←── USB Serial (115200 baud, матни сатрӣ) ──→ Arduino
```

**Протоколи содаи Serial** (ҳар фармон бо `\n` тамом мешавад):

| Фармон | Маънo |
|---|---|
| `MOVE:150,150` | чархи чап ва рост бо суръати -255..255 |
| `STOP` | истодан |
| `HEAD:90,90` | сар: pan=90°, tilt=90° |
| `EYES:0,120,255` | ранги чашм (R,G,B) |
| `EYES:MODE:LISTEN` | ҳолати чашм (IDLE/LISTEN/THINK/TALK/BLINK) |
| `PING` → `PONG` | санҷиши пайваст будан |
| Arduino → RPi: `DIST:23` | масофа то монеа (см), ҳар ~200мс |
| Arduino → RPi: `OBSTACLE` | огоҳӣ: монеа наздик, мотор худкор истод |

## 4. Кодҳои аввал

Ин репозиторий аллакай дорои коди оғозин аст:

```
firmware/arduino/robot_motion/robot_motion.ino   ← Arduino: моторҳо, сенсор, сар, чашм
raspberry_pi/
  requirements.txt
  config.example.yaml
  main.py                    ← нуқтаи оғоз, ҳама чизро мепайвандад
  brain/
    memory.py                 ← хотираи SQLite
    motion_link.py             ← пайваст ба Arduino тавассути Serial
    speech_to_text.py          ← гӯш кардан
    text_to_speech.py          ← гап задан
    ai_chat.py                 ← пайваст ба Claude API
    vision.py                  ← камера + шинохти чеҳра
```

**Насб кардан (дар Raspberry Pi):**
```bash
cd raspberry_pi
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp config.example.yaml config.yaml
# config.yaml-ро кушоед ва API key ва серияи портро (serial_port) гузоред
python3 main.py
```

**Насб кардани firmware (дар компютери худ бо Arduino IDE):**
1. `firmware/arduino/robot_motion/robot_motion.ino`-ро кушоед.
2. Китобхонаи `Adafruit_NeoPixel`-ро тавассути Library Manager насб кунед.
3. Ба Arduino Uno/Nano бор кунед (Upload).

## 6. Насб, дастҳо, пойҳо — саволҳои маъмул

Ҷавоби муфассал ба "код чи тавр ба робот медарояд", "чи тавр дастҳо мечаспонем"
ва "чаро пой нест" — дар **[docs/SETUP.md](docs/SETUP.md)**. Хулосаи кӯтоҳ:

- **Коди Arduino** — як бор тавассути Arduino IDE аз кабели USB бор мешавад ва
  дар чипи Arduino мемонад (пас аз он кабелро кандан мумкин аст).
- **Коди Python** — ба SD-корти Raspberry Pi нусхабардорӣ мешавад ва ҳар бор
  бо `python3 main.py` иҷро мешавад (метавон онро худкор дар вақти барқдиҳӣ
  оғоз кард — нигаред SETUP.md).
- **Ҳаракат** — тавассути 2 чархи мотордор + 1 чархи такягоҳ, идорашуда аз
  Arduino бо фармони `MOVE:left,right` аз Raspberry Pi.
- **Дастҳо** — дар версияи 1 нестанд; тарҳи илова кардани онҳо (сервомотор +
  плитаи PCA9685) дар SETUP.md тасвир шудааст.
- **Пой (дупоя)** — тибқи дархости аввалини шумо дар версияи 1 нест (ба ҷои
  он чарх истифода мешавад); агар дар оянда хоҳед, лоиҳаи алоҳида лозим мешавад.
